# cross-review（交叉评审）

一个 AI 智能体技能（Agent Skill）：把"多问几家 AI 再决定"和"先核实别人意见再采纳"这两件高频事项，固化为照做就行的标准流程。

## 它管两件事

| 你手里的东西 | 走哪条路 |
|---|---|
| 一个想法/方案/稿子，还没问过别人 | **路线 A · 交叉验证**：把同一个问题按统一模板分发给多个 AI/模型，逐条对比独立意见，裁决后把结论写回项目 |
| 别人（外部 AI/顾问/同事）已给的评审报告、建议清单 | **路线 B · 报告复核**：不采信报告结论，逐条取证核实"相符/偏差/未核验"，输出带验收标准的改进方案 |

## 设计原则

- **单一入口**：不需要记术语，按"你手里现在有什么"自动路由
- **零门槛**：模板里只有两类内容——原样照抄的、`{花括号}` 里填空的
- **零硬编码**：不含任何固定路径、平台绑定或环境依赖，任何支持 SKILL.md 的智能体宿主均可使用

## 三条铁律（流程内置）

1. 外部 AI 只出意见，修改只发生在自己的项目里
2. 外部结论先当线索、不当事实——核实过才算数
3. "没发现问题"不算数，除非证明真的查了

## 安装

把 `cross-review/` 目录整个放入你的智能体技能目录（通常是 `~/.<agent>/skills/` 或项目的 `.*/skills/`），宿主会自动按 `SKILL.md` 的 description 匹配触发。
